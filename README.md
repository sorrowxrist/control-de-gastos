# Control de gastos

App web simple para anotar gastos y ver cuánto queda del presupuesto del mes.

**Probala acá:** https://sorrowxrist.github.io/control-de-gastos

## Qué hace

- Define un presupuesto mensual
- Agrega y borra gastos con descripción, monto y categoría
- Muestra el total gastado, lo que queda y una barra de progreso
- Guarda los datos en el navegador (localStorage), así no se pierden al recargar
- Se adapta a celular y a modo claro/oscuro

## Tecnologías

HTML, CSS y JavaScript puro, sin librerías.

## Cómo usarla en tu compu

1. Descargá o cloná el repositorio
2. Abrí `index.html` en el navegador
